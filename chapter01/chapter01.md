## 1. 원래 업무 질문

### 내가 선택한 막연한 질문

> 요즘 재구매하는 고객이 줄어든 것 같다.

### 왜 이 질문이 모호하다고 생각했는가?

| 항목 | 구체화한 기준 |
| --- | --- |
| 대상 | `completed` 주문을 한 고객 |
| 기간 | 데이터 전체 기간인 2025-07-09~2026-07-08 |
| 기준 | 고객 단위와 월 단위 |
| 비교 방법 | 전체 재구매 고객 비율과 월별 활성 고객 중 이전 구매 이력이 있는 고객 비율 |
| 분석 목적 | 재구매 유도 프로모션의 대상과 효과 측정 기준을 정하기 위한 기초 지표 확보 |

### 분석 가능한 질문으로 다시 작성

> 2025-07-09부터 2026-07-08까지 `completed` 주문을 기준으로, 전체 기간에 2회 이상 주문한 고객의 비율은 얼마이며 월별 활성 고객 중 이전 구매 이력이 있는 고객 비율은 어떻게 변했는가?

### 결과 관찰

원래 질문에는 기간, 주문 상태, 재구매의 정의와 비교 단위가 없었다. 구체화한 질문에는 분석 기간과 `completed` 범위, 고객·월 단위, 재구매 기준이 포함되었다.

### 나의 해석과 판단

구체화 전에는 누구를 재구매 고객으로 셀지 결정할 수 없었다. 이번 분석에서는 전체 기간 중 `completed` 주문이 2회 이상인 고객을 재구매 고객으로 정의했다. 월별 분석에서는 해당 월 구매 고객 중 월 시작 전에 `completed` 구매 이력이 있는 고객을 별도로 계산했다.

### 업무·분석적 의미

재구매 고객의 규모와 월별 변화를 확인하면 유지 프로모션의 대상을 정하고, 이후 프로모션 전후 변화를 비교할 기준을 만들 수 있다.

### 한계와 추가 확인 사항

2회 이상이라는 정의에는 구매 간격이 포함되지 않는다. 실무에서는 30일·60일·90일 이내 재구매처럼 상품의 일반적인 구매 주기를 반영한 정의가 추가로 필요하다.

## 3. LLM에게 분석 질문 후보 요청

### 사용 목적

재구매율과 구매 패턴을 이해하기 위한 분석 질문 후보를 빠르게 확보하고, 각 질문에 필요한 파일과 컬럼을 검토하기 위해 사용했다.

### 사용한 Prompt

```text
온라인 쇼핑몰 데이터 분석을 준비하고 있습니다.

데이터는 다음 4개 파일로 구성됩니다.
- customers.csv: customer_id, name, gender, age, city, signup_date
- products.csv: product_id, product_name, category, price
- orders.csv: order_id, customer_id, order_date, payment_method, order_status
- order_items.csv: order_item_id, order_id, product_id, quantity, unit_price

목적은 completed 주문 기준으로 재구매 고객 비율과 구매 패턴을 이해하는 것입니다.
초보 데이터 분석자가 먼저 확인할 분석 질문 5개를 제안해 주세요.
각 질문마다 필요한 데이터 파일과 확인할 컬럼을 적어 주세요.
원인을 단정하지 말고 현재 데이터로 확인 가능한 질문만 제안해 주세요.
```

### LLM 답변 요약

1. 월별 재구매 고객 비율 추이 — `orders(customer_id, order_status, order_date)`
2. 카테고리별 `completed` 주문 금액 — `orders`, `order_items`, `products`
3. 결제수단별 취소율 — `orders(payment_method, order_status)`
4. 가입 후 첫 구매까지 걸린 기간 — `customers(signup_date)`, `orders(order_date)`
5. 연령대별 평균 구매 금액 — `customers(age)`, `orders`, `order_items`

### 결과 관찰

LLM은 고객 유지, 상품, 결제, 가입 전환, 고객 특성 등 서로 다른 방향의 질문 5개를 제시했다. 파일과 컬럼 후보도 함께 제시했으며 실제 데이터에 존재하지 않는 컬럼은 없었다.

### 나의 해석과 판단

1번은 처음 구체화한 질문과 직접 연결되므로 채택했다. 5번은 계산할 수 있지만 연령이 구매 금액의 원인인 것처럼 해석하지 않도록 문구를 수정해야 한다. 2·3·4번은 좋은 후속 질문이지만 이번 질문 범위 밖이므로 보류했다.

### 업무·분석적 의미

LLM은 분석 초기의 질문 후보를 넓히고 필요한 컬럼을 빠르게 정리하는 데 유용했다. 다만 어떤 질문을 먼저 풀지 결정하는 일은 업무 목적을 아는 사람이 맡아야 한다.

### 한계와 추가 확인 사항

LLM의 답변만으로는 컬럼의 실제 값, 결측, 타입, 키 관계와 분석 기간을 알 수 없다. 따라서 원본 CSV와 실행 결과를 이용한 검증이 필요했다.

## 4. LLM 제안 검증

| 검증 항목 | 확인 내용 |
| --- | --- |
| 선택한 LLM 제안 | 월별 재구매 고객 비율 추이 |
| 필요한 파일 | `orders.csv` |
| 필요한 컬럼 | `customer_id`, `order_date`, `order_status`, `order_id` |
| 계산 범위 | `completed` 주문만 포함 |
| 실제 상태값 | `completed` 184건, `cancelled` 64건, `refunded` 52건 |
| 실제 데이터 확인 | 컬럼·결측·타입·PK를 확인함 |
| 원인 단정 여부 | 감소 원인을 단정하지 않고 관찰된 비율만 설명함 |
| 최종 판단 | 사용 |

### 내가 수정한 내용

LLM의 “월별 재구매 고객 비율”에 분석 기간, `completed` 범위와 재구매 정의를 추가했다. 전체 재구매 고객은 분석 기간 중 `completed` 주문 2회 이상으로, 월별 재구매 고객은 해당 월 시작 전에 `completed` 구매 이력이 있는 월별 활성 고객으로 구분했다.

### 결과 관찰

필요한 파일과 컬럼은 모두 존재했다. 예상했던 두 상태 외에 `refunded`도 있었으므로 `completed`만 포함한다는 필터를 명시해야 했다.

### 나의 해석과 판단

실제 컬럼과 상태값이 있고 계산 범위도 정의할 수 있어 “사용”으로 판단했다. 단, “줄어든 이유”는 현재 데이터로 확인할 수 없으므로 질문과 해석에서 원인 표현은 제거했다.

### 업무·분석적 의미

LLM 제안을 검증하지 않으면 `refunded`를 잘못 포함하거나 서로 다른 재구매 정의를 사용해 결과가 달라질 수 있다. 분석 기준을 기록해야 같은 결과를 재현할 수 있다.

### 한계와 추가 확인 사항

첫 달 이전 구매 이력이 없기 때문에 초기 월의 재구매 비율은 실제보다 낮게 계산될 수 있다. 마지막 달은 2026-07-08까지만 포함되어 월 전체 결과가 아니다.

| 2026-05 | 11 | 11 | 8 | 72.7% |
| 2026-06 | 4 | 4 | 3 | 75.0% |
| 2026-07 | 2 | 2 | 2 | 100.0% |

### 결과 관찰

기간 전체 재구매 고객 비율은 56%였다. 월별 비율은 분석 후반에 대체로 높았으며 2026-03에는 92.3%였다. 다만 2026-07의 100%는 활성 고객이 2명뿐인 부분 월 결과다.

### 나의 해석과 판단

월별 비율이 높아진 모습은 관찰할 수 있지만 재구매가 실제로 개선되었다고 단정할 수는 없다. 데이터 첫 달에는 이전 구매 이력이 없고 마지막 달은 8일치만 있으며 월별 고객 수도 다르기 때문이다. 프로모션 효과를 판단하려면 시행 시점, 유입 채널과 고객 코호트 정보가 더 필요하다.

### 업무·분석적 의미

56%라는 전체 지표는 현재 데이터 범위의 고객 유지 수준을 설명하는 출발점이 된다. 월별 값은 변화가 큰 시점을 찾는 탐색 지표로 사용할 수 있지만, 단독으로 성과 KPI를 확정하기보다 동일 기간의 코호트 재구매율과 함께 확인해야 한다.

### 한계와 추가 확인 사항

- 2025-07 이전 주문 이력이 없어 왼쪽 절단 문제가 있다.
- 2026-07은 8일치 데이터로 월 전체와 비교할 수 없다.
- 구매 간격을 고려하지 않은 단순 2회 이상 기준이다.
- 매출 금액, 상품 카테고리와 프로모션 정보는 이번 계산에 포함하지 않았다.

## 8. Chapter 01 최종 해석

### 이번 장에서 가장 중요하다고 생각한 내용

분석은 코드를 쓰기 전에 질문과 계산 기준을 구체화하는 것에서 시작한다. LLM은 질문 후보와 코드 초안을 빠르게 제안할 수 있지만, 실제 파일·컬럼·값과 맞는지는 사람이 확인해야 한다. 같은 “재구매율”도 기간과 분모·분자의 정의에 따라 결과가 달라진다. 따라서 실행 결과뿐 아니라 관찰, 판단과 한계를 함께 기록해야 한다.

### LLM을 데이터 분석에 사용할 때 가장 조심해야 할 점

LLM이 존재하지 않는 컬럼을 제안하거나 상관관계를 원인처럼 표현할 수 있다는 점을 조심해야 한다. 실행되는 코드도 계산 정의가 잘못되면 의미가 없는 결과를 만들 수 있다. 원본 데이터와 업무 맥락을 기준으로 사람이 검증하고, 개인정보와 Secret은 Prompt와 공개 저장소에 넣지 않아야 한다.

### 사람과 LLM의 역할 차이

| 항목 | LLM이 도울 수 있는 부분 | 사람이 책임져야 하는 부분 |
| --- | --- | --- |
| 질문 정의 | 표현과 질문 후보 제안 | 업무 목적, 범위와 우선순위 결정 |
| 데이터 확인 | 필요한 파일·컬럼 후보 제안 | 실제 컬럼·값·결측·키 관계 검증 |
| 코드 작성 | pandas 코드 초안 생성 | 실행, 오류 수정과 계산 정의 확인 |
| 결과 해석 | 가능한 해석과 추가 질문 제안 | 관찰과 추측 구분, 인과관계 판단 |
| 최종 판단 | 참고 의견 제공 | 사용·수정·보류와 업무 적용 결정 |

Chapter 02에서는 동일한 환경을 직접 재현하고 Git으로 결과를 관리하는 과정을 확인하고 싶다. 이후에는 구매 간격을 포함한 30일·60일·90일 재구매율과 가입 월별 코호트 재구매율을 비교하고 싶다.
