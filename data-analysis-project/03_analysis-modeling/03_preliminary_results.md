# 본 분석·모델링·검증 — 예비 결과

실행일: 2026년 11월 6일. 기존 분석에 XGBoost를 추가하고 알고리즘과 변수 구성의 두 축으로 다시 비교했다. 교육 자료의 시점 제약 때문에 실무 배치용 사전 예측 성능이 아닌 **사후 연구용 비교**로 해석한다.

IBEX 35 수익률은 후보 변수·연도별 배경 자료다. 학습 구간이 단일 연도여서 상수이므로 아래 모델에는 투입하지 않았다. 이번 변경은 XGBoost 비교 추가이며 IBEX 35 투입 효과를 측정한 결과가 아니다. [IBEX 35 검토](../docs/ibex35_context.md).

## 1. 분석 질문과 변수

고객·계약·지역 정보를 고려한 뒤에도 보험금 비용이 다음 해 이탈 예측에 추가 가치를 갖는가?

- M0: 가입 기간 2개·보험료·상품·채널, 총 5개.
- M1: M0 + 나이·성별 + 지역 소득·교육·인구 규모·보험 가입 밀도, 총 18개.
- M2: M1 + 기준연도 보험금 비용, 총 19개.
- S1/S2: M1/M2에서 2021년 교육 지표 6개를 제외한 민감도 분석.

전체 컬럼은 [변수 구성](../docs/variable_specification.md)과 [실행 설정](analysis_results.json)에 있다. 종속변수는 다음 해 lapse 1 또는 3이며 ID·미래 종료일·다음 해 정보는 입력에서 제외했다.

## 2. 분석 방법과 검증 설계

2017년 정보→2018년 이탈로 개발하고 2018년 정보→2019년 이탈로 평가했다. 개발 내부는 계약 단위 75:25 분할이며 같은 계약이 양쪽에 겹치지 않음을 검증했다. 이번 재실행 전에 알고리즘별 설정을 고정했다. 세 알고리즘 모두 탐색 후보 1개, 추가 튜닝 0회이며 early stopping도 사용하지 않았다. 향후 튜닝은 개발 구간에서만 사전 고정한 예산과 AP 기준으로 수행한다. 기존 LR·RF 평가 결과는 이미 확인했으므로 완전히 미관측인 최종 시험이라고 주장하지 않는다.

로지스틱 회귀는 C=1, 최대 2,000회 반복, 수치 표준화와 범주 원핫 인코딩을 사용했다. 랜덤 포레스트는 트리 100개, 최대 깊이 12, 잎 최소 30개, max_features=sqrt다. XGBoost는 트리 200개, 최대 깊이 3, 학습률 0.05, min_child_weight=1, subsample=colsample_bytree=1, L2=1, L1=0, hist 방식을 사용했다. 같은 알고리즘의 설정은 M0·M1·M2·S1·S2에 동일하게 적용했다. 결측 대체·표준화·인코딩은 세 알고리즘에 동일한 방식으로 각 학습 구간에만 적합했다. 시드 20261102를 사용했다.

AP와 ROC-AUC를 함께 보고한다. AP의 기준이 되는 평가연도 이탈 비율은 11.28%다. M0/M1/M2와 S1/S2는 같은 대상에서 비교했다. 같은 계약을 함께 재표집한 paired bootstrap 200회로 성능 차이의 탐색적 95% 구간을 계산했다. 이 구간은 고정된 예측의 평가 표본 변동만 반영하며 재학습 변동은 포함하지 않는다.

## 관찰 → 해석 → 본 연구 시사점

### 알고리즘 비교 — M0

- **관찰:** 로지스틱 회귀 AP 0.1774, AUC 0.6319 / 랜덤 포레스트 AP 0.1831, AUC 0.6402 / XGBoost AP 0.1842, AUC 0.6422. AP 점추정치는 XGBoost가 가장 높다. XGBoost−랜덤 포레스트 AP 차이 +0.0011, 탐색적 95% 구간 [-0.0021, +0.0046].
- **해석:** AP 차이 구간이 0을 포함한다. 점추정치의 차이만으로 일관된 우위를 주장하기 어렵다. 이 차이는 고정한 설정에서의 비교이며 알고리즘 전체의 일반적 우위를 뜻하지 않는다.
- **본 연구 시사점:** M0의 정보를 동일하게 사용해도 학습 방식에 따라 결과가 달라진다. 성능 순위뿐 아니라 새 계약 보조 평가·오류와 설명 가능성을 함께 검토한다.

## 7. 한계와 추가 확인 사항

지역 교육 지표는 2021년 통계로 구축되어 2017·2018년 당시 이용할 수 없던 정보다. 이를 제외한 S1/S2도 나머지 지역 지표의 공표 시점과 보험금 비용 확정 시점이 입증되지 않아 과거 실무 성능으로 주장할 수 없다. 근거는 [원자료 논문 Methods](https://www.nature.com/articles/s41597-025-06372-z)다.

원본에는 유지 상태의 행에 미래 종료일이 기록되어 있어 날짜는 검증에만 사용했다. 이후 연도 평가에는 같은 계약이 일부 포함된다. 새 계약 보조 평가를 분리했지만 지역 분리 검증·외부 보험사 검증·보정도 평가는 남아 있다. 설명변수 간 상관 때문에 회귀계수나 중요도를 원인으로 해석하지 않는다. 보험료 대비 비용은 전체 수익성·CSM이 아니다.

지역 소득 지표 미확인 집단의 다음 해 이탈 비율은 2017년 기준 41.77%, 2018년 기준 7.69%로 달랐다. 모델이 지역의 경제적 특성보다 자료 누락의 패턴을 학습했을 가능성도 확인해야 한다. 이번 결과만으로 그 원인이나 각 변수의 기여를 특정하지 않는다.

## 8. 실행 및 재현

프로젝트 폴더에서 다음을 실행한다. 원자료가 없으면 먼저 기존 다운로드 코드를 실행한다.

```bash
python -m pip install -r requirements.txt
python docs/check_source_data.py
python docs/run_revised_analysis.py
python docs/render_revised_reports.py
```

버전·시드·변수·검증 결과는 analysis_results.json, 전체 성능은 metrics.csv에 기록했다. 개인별 예측이나 원자료 행은 공개 산출물에 저장하지 않았다. macOS에서 XGBoost 로딩에 libomp 오류가 나면 `brew install libomp`로 OpenMP 런타임을 설치한다. XGBoost 설정 정의는 [공식 Python API](https://xgboost.readthedocs.io/en/release_3.1.0/python/python_api.html)를 따른다. 모델 학습과 평가에 최종 연도 결과를 사용했으므로 이후 변경 사항은 이 평가 결과를 이미 확인했다는 점을 기록해야 한다.
