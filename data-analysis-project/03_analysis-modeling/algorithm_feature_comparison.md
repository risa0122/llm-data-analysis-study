# 알고리즘과 변수 구성 비교

실행일: 2026년 11월 6일. 교육 변수의 2021년 통계 사용으로 사후 연구용 비교다. IBEX 35는 단일 학습 연도의 상수이므로 학습 입력에 포함하지 않았다.

## 비교 조건

| 항목 | 공통 기준 |
|---|---|
| 알고리즘 축 | 로지스틱 회귀 / 랜덤 포레스트 / XGBoost |
| 변수 구성 축 | M0 계약 5개 / M1 고객·계약·지역 18개 / M2 보험금 비용 추가 19개 |
| 개발 분할 | 2017년 입력→2018년 이탈, 계약 단위 48,136행 학습·15,350행 검증. 계약 중복 0 |
| 이후 연도 평가 | 2018년 입력→2019년 이탈, 같은 59,831행·같은 정답 |
| 전처리 | 같은 결측 대체·표준화·원핫 방식. 각 학습 구간에서만 적합 |
| 튜닝 기준 | 재실행 전 알고리즘별 설정 1개 고정, 모두 탐색 0회·early stopping 없음. 향후 탐색은 개발 구간에서만 사전 고정한 예산으로 수행 |
| 평가 지표 | 주지표 AP, 보조지표 ROC-AUC. 설정을 최종 평가에 맞춰 변경하지 않음 |
| 변수 비교 통제 | 같은 알고리즘에서는 M0·M1·M2 모두 동일 설정 |
| 통계적 한계 | 기존 평가 결과를 본 후 확장한 연구. 완전히 미관측인 최종 시험이 아님 |

분할과 평가 대상의 해시·설정은 [comparison_audit.json](comparison_audit.json), 실행 전 고정한 계획은 [experiment_protocol.json](experiment_protocol.json)에 기록했다. 서로 다른 알고리즘에 같은 트리 수를 강제하는 대신 탐색 기회와 평가 조건을 맞췄다. 이번 비교는 각 알고리즘을 충분히 튜닝했을 때의 최대 성능 비교가 아니다.


## 두 축으로 보는 성능

행을 비교하면 같은 변수에서의 알고리즘 차이, 열을 비교하면 같은 알고리즘에서의 변수 추가 차이다. AP는 Average Precision이며 이탈을 높은 점수에 배치하는 성능을 요약한다. 값은 0~1 단위이며 정확도나 이탈 확률로 읽지 않는다.

### AP

| 알고리즘      |     M0 |     M1 |     M2 |
|:--------------|-------:|-------:|-------:|
| 로지스틱 회귀 | 0.1774 | 0.1704 | 0.1711 |
| 랜덤 포레스트 | 0.1831 | 0.1989 | 0.2018 |
| XGBoost       | 0.1842 | 0.1982 | 0.2038 |

### ROC_AUC

| 알고리즘      |     M0 |     M1 |     M2 |
|:--------------|-------:|-------:|-------:|
| 로지스틱 회귀 | 0.6319 | 0.6329 | 0.6343 |
| 랜덤 포레스트 | 0.6402 | 0.6659 | 0.6758 |
| XGBoost       | 0.6422 | 0.6689 | 0.6799 |

## 관찰 → 해석 → 본 연구 시사점

### 알고리즘 비교 — M0

- **관찰:** 로지스틱 회귀 AP 0.1774, AUC 0.6319 / 랜덤 포레스트 AP 0.1831, AUC 0.6402 / XGBoost AP 0.1842, AUC 0.6422. AP 점추정치는 XGBoost가 가장 높다. XGBoost−랜덤 포레스트 AP 차이 +0.0011, 탐색적 95% 구간 [-0.0021, +0.0046].
- **해석:** AP 차이 구간이 0을 포함한다. 점추정치의 차이만으로 일관된 우위를 주장하기 어렵다. 이 차이는 고정한 설정에서의 비교이며 알고리즘 전체의 일반적 우위를 뜻하지 않는다.
- **본 연구 시사점:** M0의 정보를 동일하게 사용해도 학습 방식에 따라 결과가 달라진다. 성능 순위뿐 아니라 새 계약 보조 평가·오류와 설명 가능성을 함께 검토한다.

- **해석:** AP 차이 구간이 0을 포함한다. 점추정치의 차이만으로 일관된 우위를 주장하기 어렵다. 이 차이는 고정한 설정에서의 비교이며 알고리즘 전체의 일반적 우위를 뜻하지 않는다.

### 알고리즘 비교 — M2

- **관찰:** 로지스틱 회귀 AP 0.1711, AUC 0.6343 / 랜덤 포레스트 AP 0.2018, AUC 0.6758 / XGBoost AP 0.2038, AUC 0.6799. AP 점추정치는 XGBoost가 가장 높다. XGBoost−랜덤 포레스트 AP 차이 +0.0020, 탐색적 95% 구간 [-0.0045, +0.0074].
- **해석:** AP 차이 구간이 0을 포함한다. 점추정치의 차이만으로 일관된 우위를 주장하기 어렵다. 이 차이는 고정한 설정에서의 비교이며 알고리즘 전체의 일반적 우위를 뜻하지 않는다.

### 변수 구성 비교 — 로지스틱 회귀 M0→M1

- **관찰:** AP 0.1774→0.1704, ROC-AUC 0.6319→0.6329. AP 차이 -0.0070, 탐색적 95% 구간 [-0.0129, -0.0002].
- **해석:** 이 평가 표본에서는 AP가 낮아졌으며 차이 구간도 0보다 낮다. 더 많은 변수나 복잡한 모형이 항상 유리한 것은 아니다. 여러 속성을 함께 추가했으므로 나이·성별·소득 한 변수의 효과로 분리할 수 없다.
- **본 연구 시사점:** 개인·지역 정보의 추가 가치는 알고리즘별 결과로 판단한다. 지역 지표를 개인의 소득·학력으로 읽지 않으며 집단별 오류와 공표 시점을 추가 확인한다.


### 변수 구성 비교 — 로지스틱 회귀 M1→M2

- **관찰:** AP 0.1704→0.1711, ROC-AUC 0.6329→0.6343. AP 차이 +0.0007, 탐색적 95% 구간 [+0.0003, +0.0012].
- **해석:** 이 평가 표본에서는 AP 증가가 관찰되며 차이 구간도 0보다 높다. 다른 기간·보험사에서도 유지되는지는 확인되지 않았다. 고객·계약·지역 정보를 유지한 상태에서 보험금 비용을 추가한 예측 차이다. 비용이 이탈을 일으켰다는 뜻은 아니다.
- **본 연구 시사점:** 보험금 비용의 추가 가치는 알고리즘별 결과로 판단한다. 이탈 예측의 추가 정보로 검토하되 실제 상담 효과·이익·CSM 개선액으로 환산하지 않는다.
