# 프로젝트 변경 기록

## 2026년 11월 2일 — IBEX 35 추가

사용자 요청에 따라 스페인 IBEX 35의 2017~2019년 연간 가격수익률을 확보했다. BME 공식 연말 값으로 계산하고 기준연도 수익률을 다음 해 이탈 코호트에 연결했다. 2017년 단일 학습 구간에서 고유값 1개임을 확인해 후보 변수·경제 배경 자료로 추가했다. 기존 모델에 투입해 효과를 학습했다고 주장하지 않으며 기존 성능은 유지한다. 자세한 근거는 [IBEX 35 검토](ibex35_context.md)에 기록했다.

## 2026년 11월 2일 — 개인·지역 변수 포함

- 기존 설계는 계약 변수와 보험금 비용에 집중하고 나이·성별·지역 지표를 제외했다. 이 제외를 뒷받침할 실증 근거가 없어 사용자의 검토 의견에 따라 수정했다.
- 나이·성별·지역 소득·교육·인구 규모·보험 가입 밀도를 기본 모델에 포함하고, 확장 모델에 보험금 비용만 추가하도록 변경했다.
- 원자료와 설명서의 체크섬을 확인한 후 원본에서 EDA와 예비 모델 비교를 새로 실행했다. 기존 성능을 재현한 것이 아니라 이번에 처음 생성한 예비 결과다.
- 원자료 논문에서 지역 교육 변수의 2021년 통계 사용을 확인했다. 전체 지역 지표 모델은 사후 연구로 제한하고, 교육 지표 제외 모델을 함께 비교했다.
- 기획서의 1~7번 구성을 유지하고 변수 설명서, EDA·모델 결과, README와 AI 활용 기록을 갱신했다. 발표용 최신 자료는 로컬에만 관리한다.
- 날짜가 붙은 10월 발표·백업 파일은 당시 기록으로 보존하며 최신 분석으로 사용하지 않는다. 새 이식 자료는 2026년 11월 2일 버전으로 구분한다.

## 남은 확인

개별 지표 공표 시점, 데이터 시점에 맞는 지역 자료 재구성, 지역 단위 외부 검증, 모델 보정·설명 가능성, 고객·계약·지역을 동시에 고려한 비용 비교의 추가 검증이 남아 있다. 실제 이탈 방어 효과와 CSM 금액은 이번 자료로 검증할 수 없다.
