# IBEX 35 경제 상황 변수

## 1. 정의와 사용 목적

IBEX 35는 스페인 주식시장의 유동성이 높은 35개 종목으로 구성된 대표 지수다. 한국의 코스피처럼 시장 흐름을 참고하는 역할을 하지만 구성 범위는 같지 않다. 스페인 주식시장 상황을 나타내며 세계 경제 전체, 가계 소득 또는 개인의 보험료 납입 여력을 직접 측정하지 않는다.

후보 독립변수 `ibex35_return_pct`는 **기준연도 IBEX 35 연간 가격수익률(%)**이다. 배당을 포함한 총수익률이 아니다. 연말 지수 수준은 계산·검증용으로 보관하며 수준과 수익률을 무조건 동시에 투입하지 않는다.

## 2. 실제 확보한 값

| 연도 | 연말 지수(포인트) | 연간 가격수익률 |
|---|---:|---:|
| 2016 | 9,532.10 | 2017년 수익률 계산 기준 |
| 2017 | 10,043.90 | +5.37% |
| 2018 | 8,539.90 | −14.97% |
| 2019 | 9,549.20 | +11.82% |

수익률은 `(당해 연말 지수 ÷ 전년 연말 지수 − 1) × 100`으로 계산했다. 소수점은 표시할 때만 반올림한다.

## 3. 분석 대상과 연결

2018년 이탈을 예측할 때는 2017년 수익률, 2019년 이탈을 예측할 때는 2018년 수익률을 연결한다. 2019년 수익률은 전체 기간 설명용이며 2019년 이탈의 예측 입력에 넣지 않는다. 연말 종가가 확정된 이후를 예측 시점으로 가정한다. 자료 확인은 사후 발간된 연차보고서로 했으며 값 자체는 당시 장 마감 후 관측 가능한 시장 가격이다.

## 4. 기존 연간 모델에서의 처리와 검증

후보 변수 목록과 연도별 분석 자료에 추가했다. 기존 연간 모델의 개발 자료는 2017년 한 해이므로 모든 고객에게 동일한 수익률이 반복된다. 실제 학습 구간의 고유값 수는 1개다. 상수 변수로는 경기 변화의 효과를 추정할 수 없어 기존 M0/M1/M2/S1/S2 학습에는 넣지 않았다. 기존 모델의 변수 개수와 성능은 그대로이며 IBEX 35를 반영한 새 성능이라고 부르지 않는다.

두 개 연도 코호트의 이탈 비율과 주가 수익률만으로 상관계수·인과효과를 추정하지 않는다. 고객 행이 많아도 독립적인 경기 관측 시점은 늘지 않는다. 여러 해의 보험 자료 또는 누수 없이 구성한 월별 위험집합 자료를 확보한 후 독립변수 효과를 검증한다. 연간 계약 행을 임의로 월별 복제하거나 종료일로 주가 값을 선택하지 않는다.

## 6. 월별 모델 실제 반영 — 2026년 11월 6일

BME 공식 월별 종가를 확보하고 월초 예측에 전월 수익률을 연결했다. 2018년 월별 학습과 2019년 월별 평가 각각에 12개의 값이 들어간다. M0~M2에 공통으로 월 원핫 변수를 적용하고 M3에 IBEX를 추가하여 세 알고리즘에서 실행했다.

월별 패널은 전년도 말 유지 관계를 대상으로 구성하며, 당해 신규 가입자를 제외하고 종료 후 관측을 제거한다. 연간 보험 정보는 전년도 값으로 고정한다. 시장 정보의 독립 관측 시점은 고객 행 수가 아니라 월 수다. 한 해 학습으로 계절성과 독립된 시장 효과를 식별할 수 없으므로 예비 절차 검증으로 해석한다.
