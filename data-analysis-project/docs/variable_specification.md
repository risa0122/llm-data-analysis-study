# 분석 변수 구성

수정일: 2026년 11월 2일. 원자료 V4의 변수 설명서를 기준으로 작성했다.

## 1. 분석 단위와 종속변수

한 행은 피보험 관계(ID)의 연도별 기록이다. 기준연도 `lapse=2`를 다음 해 같은 ID와 연결하고, 다음 해 `lapse=1/3`을 이탈, `2`를 유지로 정의한다. 다음 해 기록 미확인 3건은 제외하고 별도 기록한다. 이탈은 피보험 관계 종료이며 고객 전체의 보험사 이탈이나 해지·실효 사유를 뜻하지 않는다.

## 2. 독립변수

| 구분 | 컬럼 | 의미 | 처리 |
|---|---|---|---|
| 개인 | `age` | 반올림한 피보험자 나이, 0~99세 | 연속형. EDA는 연령대별 비교 |
| 개인 | `gender` | F: 여성, M: 남성 | 범주형 |
| 계약 | `seniority_insured`, `seniority_policy` | 피보험자 가입 기간, 계약 유지 기간 | 연속형 |
| 계약 | `premium` | 기준연도 보험료, 유로 | 연속형 |
| 계약 | `type_product`, `distribution_channel` | 상품 유형, 판매 채널 | 범주형 |
| 지역 소득 | `C_GI` | 우편번호 지역 소득의 일반 인구 기준 백분위 | 1~100 순위형 수치. 개인 연소득이 아님 |
| 지역 소득 | `C_II` | 우편번호 지역 소득의 보험사 포트폴리오 기준 백분위 | 1~100 순위형 수치 |
| 지역 교육 | `C_GE_P`, `C_GE_S`, `C_GE_T` | 지역의 초등 이하·중등·고등교육 특성, 일반 인구 분포 기준 백분위 | 개인 학력이 아님. 2021년 통계 사용 |
| 지역 교육 | `C_IE_P`, `C_IE_S`, `C_IE_T` | 같은 교육 특성, 보험사 포트폴리오 분포 기준 백분위 | 개인 학력이 아님. 2021년 통계 사용 |
| 지역 인구 | `C_H` | 지자체 인구 규모 H1~H6 | 범주형. ≤1천, 1천~1만, 1만~2.5만, 2.5만~5만, 5만~10만, 10만 초과 |
| 지역 보험 가입 밀도 | `IICIMUN`, `IICIPROV` | 지자체·주별 인구 1,000명당 해당 보험사 피보험자 수 | 해당 보험사의 지역 침투도이며 지역 전체 보험 가입률이 아님 |
| 확장 변수 | `cost_claims_year` | 기준연도 피보험자 의료 보험금 비용, 유로 | M2에만 추가. 0은 비용 발생 없음 |

지역 소득·교육 지표는 백분위이므로 금액이나 해당 지역 주민 비율로 읽지 않는다. 개인에게 지역 평균의 특성을 직접 부여해 해석하지 않는다. 기후 변수 `C_C`와 단순 지역 피보험자 수는 이번 사회경제 변수 구성에서 제외했다.

## 3. 모델 비교

| 모델 | 변수 구성 | 확인할 내용 |
|---|---|---|
| M0 | 기존 계약 변수 5개 | 기존 설계의 비교 기준 |
| M1 | M0 + 나이·성별 + 지역 지표 11개 = 18개 | 개인·지역 정보를 함께 추가한 예측 차이 |
| M2 | M1 + 보험금 비용 = 19개 | 개인·계약·지역 정보를 고려한 후 보험금 비용의 추가 가치 |
| S1 / S2 | M1 / M2에서 교육 변수 6개 제외 | 사후 교육 통계 포함 여부에 대한 민감도 |

나이와 성별, 지역 지표를 M1·M2에 동일하게 사용한다. M0→M1 차이는 이 정보를 합쳐 추가한 차이이며 개별 변수의 인과 효과가 아니다. ID·계약 ID·순번·다음 해 정보·종료일은 모델 입력에서 제외한다. 의료서비스 횟수는 이번 보험금 비용 추가 비교에 포함하지 않는다.

수치형 결측은 학습 자료의 중앙값으로 대체하고 결측 표시를 추가한다. 범주형은 Unknown으로 구분하고 원핫 인코딩한다. 지역 미확인 집단은 EDA에서도 별도로 제시한다. 같은 지역 정보를 나타내는 변수 간 상관이 높을 수 있어 회귀계수를 원인이나 독립 효과로 해석하지 않는다.

## 4. 관측 시점과 분석의 한계

[원자료 설명 논문](https://www.nature.com/articles/s41597-025-06372-z)의 Methods에는 교육 변수를 2021년 통계에서 가져와 2017~2019년 지역 순위가 안정적이라고 가정했다고 명시한다. 따라서 전체 지역 지표를 포함한 결과는 **사후 연구용 예비 분석**이다. 연도를 나누어 평가해도 이 시점 문제는 해결되지 않는다.

교육 지표를 뺀 S1/S2도 다른 지역 지표의 공표·산출 시점과 보험금 비용 확정 시점이 모두 입증된 것은 아니다. 실제 업무 배치용 예측 성능으로 주장하지 않는다. 원자료에는 유지 상태인 과거 연도 행에 미래 종료일이 기록된 경우도 있어 날짜 컬럼은 검증에만 쓰고 예측에서는 제외한다.
