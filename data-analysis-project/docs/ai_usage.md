# 생성형 AI 활용 및 검증 기록

## 1차 — 데이터분석 프로젝트 기획

작성일: 2026년 10월 4일

| 구분 | 내용 |
|---|---|
| 활용 목적 | 보험계약 이탈 분석을 위한 공개 데이터 탐색과 분석 계획 수립 |
| 활용 도구 | Codex |
| 활용 내용 | 분석 질문 구체화, 데이터 출처·변수 확인, 확보 및 점검 코드 작성, 기획서 작성 |
| 실제 실행 결과 | 원자료·설명서 다운로드 및 체크섬 확인. 228,711행·42열, `ID`와 `period` 조합 중복 0건 |
| 결과 관찰 | 다음 해 상태를 확인할 수 없는 기록은 2017년 기준 1건, 2018년 기준 2건 |
| 해석 및 판단 | 연도 간 연결 분석이 가능하다. 결과 미확인 기록은 이탈로 간주하지 않는다. |
| 검토 후 반영 내용 | 계약 내 순번이 아닌 `ID`로 연결. 미래 종료 정보 제외. 이탈 예측 성능과 상담 효과 구분. 관리 대상 20%라는 가정을 제외하고 이탈 비율·보험료 규모 비교로 질문 수정. 보험료와 CSM 구분 |
| 후속 기획 변경 | 이탈 비율과 관리 우선순위 질문의 중복을 줄이기 위해 이탈·유지 집단의 과거 보험금 비용 비율 비교와 비용 정보의 추가 예측 가치 검증으로 구체화 |
| 검증 기준 보완 | 보험료와 보험금 비용을 구분하고, 같은 대상·알고리즘에서 보험금 비용 추가 여부만 비교. 이후 연도 비용은 입력에서 제외 |
| 한계 및 추가 확인 사항 | 상태·날짜 일치, 보험금 비용 확정 시점, 보장 기간·상품 구성 차이와 모델 성능은 후속 단계에서 검증 |

실행 근거는 [데이터 점검 코드](check_source_data.py), [점검 결과](data_feasibility.json), [수집 파일 기록](../data/source_manifest.json)에 남겼다. 이후 AI 제안, 실제 실행 결과, 수정 이유와 최종 판단을 구분해 누적한다.

## 2026년 11월 2일 — 변수 구성 수정과 예비 분석

| 구분 | 내용 |
|---|---|
| 사용자 검토 의견 | 나이·성별·지역 사회경제 지표를 분석에 포함해야 한다는 지적 |
| 기존 제안의 문제 | 개인·지역 변수 제외를 뒷받침할 실증 근거가 부족했고 계약 변수만으로 분석 범위를 좁힘 |
| 수정 내용 | 나이·성별·지역 소득·교육·인구 규모·보험 가입 밀도를 기본 모델에 포함. 보험금 비용 추가 모델과 동일 조건 비교 |
| 추가 발견 | 원자료 논문에 교육 지표의 2021년 통계 사용이 명시됨. 유지 상태의 과거 행에도 미래 종료일이 기록되어 있음 |
| 검증·처리 | 체크섬·ID/연도 중복·상태/날짜 대조, 계약 단위 개발 분할, 이후 연도 평가, 교육 제외 민감도, 계약 단위 재표집 |
| 실제 실행 결과 | 이번에 새로 생성한 그룹별 EDA와 예비 모델 성능을 연결된 결과 파일에 기록. 기존에 모델 결과가 있었던 것으로 서술하지 않음 |
| 오류 수정 | 집계 생성 시 pandas 인자 오류 수정. 지역 밀도의 사분위 경계가 중복되어 고유 경계만 사용하도록 수정 |
| 해석 기준 | 지역 값은 개인 소득·학력이 아님. 전체 지역 지표 모델은 사후 연구이며 실무 사전 예측이나 인과 효과로 해석하지 않음 |
| 남은 확인 | 지역 지표 공표 시점, 보험금 비용 확정 시점, 외부 검증·집단별 오류, 동시 구성 통제를 통한 비용 비교 |

실행 코드: [재분석](run_revised_analysis.py), [결과 문서 생성](render_revised_reports.py). 결과: [EDA](../02_data-eda/02_eda_report.md), [예비 모델](../03_analysis-modeling/03_preliminary_results.md). 사용자가 새 결과를 직접 확인·승인했다고 기록하지 않는다.
